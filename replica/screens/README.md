# replica/screens/

Сюда складываются референсные скриншоты оригинала. Они используются только для
сравнения раскладки в `replica-diff` и **никогда не попадают в сам клон**.

В этом учебном прогоне скриншоты не снимались (нет живого аккаунта и браузер-инструмента).
Публичный листинг Google Play содержит превью-скриншоты по прямым URL — их можно добавить сюда
позже для честного layout-диффа.

Формат имени: `S01_main_list.png`, `S02_create_habit.png`, ...
